# 把国家台并进四川目录（v1.9.10）

## 需求

> 将国家台，在四川那个目录下面复制放一份，相当于四川的目录里面有四川的电台以及国家的电台。

原状态：国家台（中国之声、经济之声……）只存在于「国家」文件夹（接口 `provinceCode=0`）。
在四川目录里看不到它们，想听要先切文件夹、听完再切回来——车机上每切一次都要点两下，
开车时不方便。

## 做法：复制，不是搬移

| 项 | 处理 |
|---|---|
| 触发条件 | 当前目录 `provinceCode == 510000`（四川） |
| 数据来源 | 额外拉一次 `RadioCnApi.fetchStations(0)`（实测只返回中央台，19 个左右） |
| 落位 | 追加在四川列表尾部，由 `StationSorter.provinceFirst` 归到第三档 —— 顺序正好是「省台 → 成都台 → 国家台」 |
| 「国家」文件夹 | **原样保留**，两边同一个 `contentId`、同一条流；收藏 / 隐藏 / 续播按 `contentId` 走，天然一致 |
| 去重 | 四川列表里已有同 `contentId` 或同名台的，跳过，不会出现两个「中国之声」 |

## 两个容易踩的细节

**① 复制体的 `provinceCode` 必须保持 0。**
这个字段决定「地址过期后去哪张列表补地址」（`RadioCnApi.refreshStationUrls`）：

```java
if (target.provinceCode > 0 && fillFrom(target, fetchStations(target.provinceCode))) return true;
if (target.provinceCode <= 0 && fillFrom(target, fetchStations(0))) return true;   // ← 国家台走这条
```

若图省事把它写成 510000，刷新时会去四川列表里找「中国之声」——找不到，地址补不上，
表现就是界面已经切过去了、声音一直不来。

**② `provinceName` 改成「国家」。**
列表副标题（`MainActivity.subOf`）、媒体条第二行（`EasPlaybackInfo.getArtist`）、
播放通知（`RadioPlayer`）都用它，显示成「国家 · 正在直播：…」一眼能看出是中央台。
若沿用「四川」，用户会误以为中国之声是省台。

## 代码位置

| 文件 | 改动 |
|---|---|
| `NationalStations.java`（新增） | 纯函数 `mergeInto(data, national, provinceCode)`，返回新列表，不改入参；`copy()` 复制一条台并改归属 |
| `MainActivity.loadStations()` | 四川时多拉一次国家台列表，失败单独 try/catch（只少几个台，不影响省级列表）；日志 `拿到 N 个电台（含并入的国家台 M 个）` |
| `NationalStationsTest.java`（新增） | 7 项：追加位置、省份码为 0、复制体独立、去重、非四川不动、拉取失败不丢台、排序把国家台放最后 |

## 缓存与刷新

- 列表缓存 `cachedStations` 按省份码存，四川这一份含国家台，热启动直接复用，不会多一次网络。
- `StreamCache` 按 `contentId` 存地址，两份复制体共用同一条缓存，不会重复占空间。
- 想给别的省也这样：改 `NationalStations.mergeInto` 里的省份判断即可，逻辑与四川完全一致。
