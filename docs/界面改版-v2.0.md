# 界面改版 v2.0 —— 参考喜马拉雅 FM

> 范围：外观与版式重做，功能一行没动（播放、列表、收藏、省份、更新、诊断全部照旧）。
> 两套界面（车机两栏 / 手机单列）同时改，配色与字号打通。

## 1. 方向（动手前先定的五行）

| 项 | 内容 |
|---|---|
| **产品** | 给吉利星愿车机做的网络收音机，替代原厂调谐器，按省份选台、方向盘可控 |
| **性格** | 明亮、清楚、带一点市集的热闹（是有人的电台，不是冷峻的仪器） |
| **世界** | 收音机面板与调频刻度盘：白色哑光塑料、细刻度、橙色指针 |
| **时刻** | 两处：左侧播放卡的台标（唯一的图像焦点）＋ 节目时间轴（一条刻度）；列表里正在播的那一行 |
| **签名** | 「调频指针」——时间轴刻度 + 正在播行左侧 3dp 橙条；橙色只代表「正在播」这一件事 |

喜马拉雅的语言是「白卡 + 灰底 + 大封面 + 橙只用于强调」，所以整屏只有三处橙：
正在播的行、主播放键、选中的标签。

## 2. 审计：旧版（v1.9.x 深色）查出的问题

| 类别 | 问题 |
|---|---|
| 配色 | 深色一整片（`#0E1013`），台标、台名、列表全糊在同一层，没有轻重 |
| 配色 | 十几个十六进制散在 selector 里（`#2C333C`/`#1B1F25`/`#22272E`/`#FF6B1A`/`#E06400`…），改主题要翻十几个文件 |
| 配色 | 四种灰（`#C8CFD8`/`#9BA3AF`/`#6B7480`/`#5F6875`）分不清谁是二级谁是三级 |
| 间距 | `7dp` / `3dp` / `14dp` / `18dp` 混用，不在 4pt 网格上 |
| 层次 | 顶栏 5 个按钮（版本/隐藏/更新/诊断/地区）同底同字号，没有主次 |
| 图标 | 隐藏用字符「⊘」，依赖设备字体 glyph，且基线导致上下不居中 |
| 文案 | 「FM 直播」是带字距的全大写装饰标签；「● 正在直播」「❚❚ 已暂停」用字符当图标 |
| 视觉 | 台标是圆形描边圈，方形台标四角被切；整屏没有「一个亮点」 |

## 3. 设计 token

### 颜色（`res/values/colors.xml`）

| 角色 | 名称 | 值 | 用途 |
|---|---|---|---|
| 页面底 | `bg` | `#F4F5F7` | 托住白卡片 |
| 卡片 | `panel` | `#FFFFFF` | 左栏播放卡、右栏列表卡、手机播放条 |
| 次级面 | `surface_muted` | `#F2F4F7` | 小胶囊、圆钮底、按下态 |
| 分隔线 | `divider` | `#EBEDF0` | 台标发丝边、时间轴轨道 |
| 强调 | `accent` | `#FF6600` | 喜马橙：正在播、主键、选中标签 |
| 强调按下 | `accent_pressed` | `#E65C00` | 同色相压暗一档 |
| 浅橙底 | `accent_wash` | `#FFF1E8` | 选中行、直播胶囊 |
| 浅橙上的字 | `accent_deep` | `#C2410C` | 在 `#FFF1E8` 上约 5:1（用 `accent` 只有 3:1，小字不够） |
| 文字 1/2/3 | `text_primary`/`text_secondary`/`text_hint` | `#16181D`/`#5A6270`/`#9AA0AB` | 只有三级，不再细分 |
| 图标 | `icon_secondary` | `#4A5058` | 浅灰底上的上一台/下一台/隐藏 |
| 橙底上的图标 | `icon_on_accent` | `#FFFFFF` | 主播放键、选中标签文字 |

### 字号（车机 / 手机）

| 元素 | 车机 | 手机 |
|---|---|---|
| 台名（播放卡） | 34sp medium | 17sp medium |
| 列表台名 | 22sp medium | 16sp medium |
| 列表副标题 | 14sp | 11sp |
| 段落/时段 | 16sp / 15sp | 11sp |
| 时间轴刻度 | 13sp | 10sp |
| 顶栏胶囊 | 14sp（地区 15sp） | 12sp（地区 14sp） |
| 分段标签 | 16sp | 15sp |

字重只用两档：regular 400 与 `sans-serif-medium`（500）。全屏没有 700 ——
中文在 700 下笔画会糊，上一版台名用 bold 就是为了"看着大"，其实靠字号就够。

### 圆角

卡片 20dp · 按钮 24dp · 列表项 12dp · 胶囊 20dp（= 高度一半）· 小标签 8dp。
内层圆角一律小于外层，不出现「大卡片里塞一个更圆的块」。

## 4. 逐项改动

### 间距
全部落在 4dp 网格。车机根 padding 12、左卡内 20/16、按钮行 88 固定；
手机根 12/8、播放条内 12/10。序号列、台名列、图标列各自对齐成一列。

### 颜色
换成上面一套 token，所有 drawable 与代码只引用 `@color/xxx`。
浅色日志面板同步压深（`log_key` 蓝 / `log_warn` 琥珀 / `log_error` 红），
原来那套亮色（`#4FC3F7`）在白底上几乎看不见。

### 图标
- 上一台 / 下一台改深灰：浅灰底上白色图标等于消失（原来它们和主键共用白色）
- 主播放 / 暂停保持白色：橙底上必须白
- 「⊘」→ 新增 `ic_hide.xml`（Material visibility_off 路径）
- 「●」「❚❚」→ 新增 `dot_live.xml`（固定 8dp 圆点），暂停时圆点隐藏

### 文案
- 「FM 直播」→ 去掉，标题位置改用应用名（`@string/app_name`，Carlink 版自动是「星愿 FM」）
- 「● 正在直播」→「正在直播」；「❚❚ 已暂停」→「已暂停」
- 「点 ⊘ 隐藏」→「点右侧的眼睛图标隐藏」

### 布局
车机：左 46% / 右 54% 不变，但左栏变成一张白卡（居中排布），右栏变成另一张白卡
（顶栏 + 分段 + 列表）。手机：标题行 / 工具行 / 分段 / 列表 / 底部播放条五段。

### 细节
- 台标由圆形改**圆角方形**（24dp 圆角）：央广网的台标多是带文字的方图，圆形会切掉笔画
- 台标底加 1dp 发丝边：白底台标不显边界，深色台标也有个轮廓
- 列表选中：浅橙底 + 左侧 3dp 橙条（`item_mark`，用独立 View 而不是 layer-list，
  因为 minSdk 21 没有 `android:width` on item）
- 收藏键已收藏时：浅橙底 + 橙描边 + **深橙**心形（`accent_deep`）。
  同色相拉明度，避免上一版「橙心糊在橙圈里」
- 焦点态统一「白底 + 2dp 橙描边」，不用发光/渐变

### 动效
没有新增。车机界面上一秒都不该有东西自己动 —— 保留按下态与焦点态的即时反馈即可。

## 6. 上车怎么验

1. 打开是白底、两张卡片，橙只出现在主播放键 / 正在播那一行 / 选中的标签；
2. 左栏台标是圆角方图（不是圆），下方台名、时段、刻度、状态依次排开；
3. 列表里正在播的那一行有浅橙底 + 左侧橙条；其它行纯白；
4. 方向盘扫过按钮时是「白底 + 橙描边」；
5. 暂停时圆点消失、文字变「已暂停」且转灰；
6. 右下角仍是 `v2.0.0`，点开「关于」渠道显示「Carlink 自用版」。

## 7. 没做的

- **夜间模式**：浅色在白天清楚，夜里可能偏亮。车机全局有夜间主题的话可以再叠一套
  `values-night`，色板已经集中在一处，改起来只动一个文件。
- **台标占位图**：现在仍是「台名首字」字标，没有做插画式占位。
- **正式版的自动更新**：`com.rea.radio` 的更新地址仍是私有仓库 `cxcl20057/xinyuan-radio`
  （匿名访问实测 404）。要修得另建一个只放 APK 的公开分发仓库，或给它加只读令牌；
  把现有仓库设 public 会一并公开 `keystore/` 与默认签名口令，不能这么做。
