# 星愿收音机 · 介绍视频文案

> 用途：产品介绍短视频（GitHub README / 应用商店 / 自媒体）
> 版本：30 秒版（需 60 秒版见文末「镜头拉伸说明」）

---

## 一、视频定位

| 项 | 说明 |
|---|---|
| 时长 | **30 秒** |
| 画幅 | 16:9 横屏，1920×1080 |
| 风格 | 真实界面 + 大字标注，干净克制，不做花哨特效 |
| 主色 | 橙 `#FF6600`（品牌色），辅以深灰 `#1F2937`、浅灰 `#F2F4F7` |
| 节奏 | 片头渐入 → 车机 → 亮点 → 手机 → 片尾渐出，全程轻快 |

---

## 二、分镜脚本（5 镜）

| 镜号 | 时间 | 画面 | 字幕 / 旁白 | 运镜与转场 |
|---|---|---|---|---|
| **1 片头** | 0–3s | 橙色渐变底，居中「星愿收音机」Logo + 声波图标 | 星愿收音机——纯净 FM，为车机而生 | 淡入 |
| **2 车机** | 3–11s | 车机横屏两栏界面：左播放卡（台标+台名+按钮）、右电台列表 | 上车自动接管方向盘按键，按城市自动列出当地电台 | 缓慢推进，淡入淡出 |
| **3 亮点** | 11–18s | 车机界面局部，叠加「无广告 / 音质择优 / 断流重连」关键词标注 | 音质自动择优，断流自动重连；无广告、无开屏、无登录 | 关键词逐条弹出 |
| **4 手机** | 18–24s | 手机竖屏单列界面，白天 / 夜间双主题并排 | 手机同样好用，白天、夜间双主题随环境切换 | 双图并排，交叉淡化 |
| **5 片尾** | 24–30s | 品牌橙底，居中名称 + 开源引导 | 星愿收音机，让广播回到它本来的样子 | 淡出 |

## 三、完整口播稿（可直接配音）

> 约 120 字，正常语速（4 字/秒）配 30 秒正合适。以下一段直接复制给配音工具即可：

星愿收音机，纯净 FM，为车机而生。上车自动接管方向盘按键，按城市自动列出当地电台；音质自动择优，断流自动重连，无广告、无开屏、无登录。手机同样好用，白天、夜间双主题随环境切换。星愿收音机，让广播回到它本来的样子。

## 四、给豆包的生成建议

1. **若用「文生视频」**：把下面这段提示词整段粘贴，再把 3 张界面截图作为参考图上传：

   > 一段 30 秒的安卓收音机 App 产品介绍视频，16:9 横屏。片头是橙色渐变背景配「星愿收音机」文字 Logo；中段展示车机横屏两栏界面（左侧播放卡、右侧电台列表）和手机竖屏单列界面（白天/夜间双主题）；片尾橙色背景配「星愿收音机，让广播回到它本来的样子」。画面干净克制，字幕用大号粗体中文，主色橙色 #FF6600。

2. **若用「图生视频 / 视频配音」**：上传 `docs/car-screen.png` 与 `docs/phone-preview.jpg`、`docs/phone-dark.jpg`，配音用第三节的口播稿。

3. **配音语速**：选「正常 / 中速」，关键词（纯净、方向盘按键、音质择优、双主题）可加 0.2 秒停顿强调。

4. **BGM**：轻快温暖的无版权电子/轻音乐，片头 0–3s 渐入、片尾 24–30s 渐弱收尾。
