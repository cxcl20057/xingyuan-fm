车机网络收音机 · 功能需求文档

用途：交付给第三方开发者作为重新开发的依据。 本文只写「要什么功能、什么规则、怎么算做对」，不规定技术实现、不附源码。 唯一约束：目标设备的系统能力（见第 1 节），实现方式自选。

0. 一句话需求

做一个装在车机上、能用方向盘按键控制的网络收音机：无广告、无登录、无开屏，打开就出声；按所在地自动列出当地电台（四川优先）；关掉界面切到导航，音频和方向盘都还在；下次开车回到上次那个台。

1. 运行环境与硬约束

项 值 说明
系统 Android 9.0 / API 28 minSdk 28、targetSdk 28
屏幕 1920×1080 横屏，密度 2x（≈960×540dp） UI 以横屏两栏为基准设计
CPU ECARX 8 核，arm64-v8a 兼容 v7a；不得依赖仅 arm64 的 native 库
内存 物理 5.69G + 虚拟 2G 常规占用即可，无特殊限制
网络 车机 4G 热点 必须能容忍弱网、断网、切换网络
输入 触摸屏 + 方向盘按键 + （可选）旋钮 方向盘按键是硬需求
调试 无 USB 调试条件 日志必须在应用内可视，不能只输出到 logcat

硬约束：

  1. 零第三方运行时依赖优先。若引入播放器/网络库，需说明体积与许可证。
  2. 不得内置任何广告 SDK、统计 SDK、推送 SDK。
  3. 不得内置任何音频内容，所有音频实时从公开接口拉取，不下载不转存。
  4. 安装包体积目标 ≤ 1 MB（参考实现为 76 KB）。

3. 功能详细规格

F1 · 自动定位并列出当地电台

行为

  1. 首次启动（无历史记录）时，通过公网出口 IP 判断所在省级行政区。
  2. 拿到省份后，拉取该省电台列表并渲染。
  3. 定位超时 4 秒必须放弃，回落默认省份（四川），不得让界面空等。
  4. 定位失败、接口失败、无网络，一律回落默认省份，并照常显示可用列表。

规则

  • 只取到省级粒度，城市名仅用于界面显示，不参与筛选。
  • 定位得到的省份不写入"用户手选"标记（见 F10），下次启动可重新定位。
  • 提供内置省份清单作为兜底：接口拿不到省份列表时，用内置的 34 个省级行政区 + 国家台渲染下拉框。

验收

  • 全新安装、有网 → 3 秒内出现本省电台列表
  • 断网启动 → 不白屏、不崩溃，显示默认省份列表或明确的空态提示
  • 定位接口超时 → 4 秒后自动回落，无用户等待

F2 · 电台列表排序

规则（三档排序，档内保持接口返回顺序）

档位 判定条件 例子
一档 台名以本省省名开头，且不含城市名 四川交通广播、四川新闻广播
二档 台名含省名或城市名（排除国家级） 中国交通广播（四川）、成都经济广播
三档 其余 中国之声、经济之声等国家台

省级下拉框顺序：四川 → 重庆 → 云南 → 贵州 → 其它（可按客户要求调整）。

验收

  • 四川列表首屏前 5 台全部是「四川 XX」开头
  • 国家台排在本省台之后

F3 · 播放控制

必须提供的操作

操作 触摸 手势 方向盘
播放 / 暂停 中央大按钮 — 播放暂停键
上一台 左按钮 右滑或下滑 上一曲
下一台 右按钮 左滑或上滑 下一曲

关键规则

  1. 单击必须生效，不允许「第一次点击只移光标、第二次才触发」。 - 常见坑：控件设了 focusableInTouchMode=true 后，触屏第一次点击只获取焦点。不要设。
  2. 切台走播放队列，不走屏幕可见列表： - 队列包含被隐藏的台？→ 不包含。隐藏必须同步移出队列，否则方向盘会切到看不见的台。 - 收藏视图下切台，队列 = 收藏列表。 - 队列循环：最后一台下一台回到第一台。
  3. 任一操作后，列表高亮必须与正在播放的台一致（见 F7 的"列表跟随"）。

验收

  • 三个按钮各单击一次即响应（不是两次）
  • 连按「下一台」15 次，切到的台与高亮行始终一致
  • 在收藏视图切台，只在收藏范围内循环

F4 · 音频流播放与降级

地址获取

  • 播放地址由接口返回，带签名参数，会随时间变化。
  • 不得持久写死完整地址；应当播放时重新申请，或做有时限的本地缓存。
  • 单台通常返回 4 个候选地址，优先级：多码率流 → MP3 低码率 → MP3 高码率 → HLS。

降级链（必须实现）

级别 触发条件 动作
1 播放开始 用缓存地址（30 分钟内）秒开，不等待网络
2 播放失败 依次换下一个候选地址，单台最多重试 2 次
3 候选耗尽 重新向接口申请该台的最新地址，再试一次
4 仍失败 提示「该台暂时无法播放」，只影响这一台，不整体报错

复用规则

  • 地址缓存有效期：30 分钟内视为新鲜，直接复用；6 小时后过期，必须重新申请。
  • 中途失败则强制刷新，不许一直用坏地址。

验收

  • 断网播放 → 提示明确，界面不卡死
  • 手动把缓存地址改成错误值 → 自动降级到下一候选并恢复播放
  • 单台故障时，切换到其它台仍正常

F5 · 方向盘按键控制

项 要求
按键 上一曲 / 下一曲 / 播放暂停（media button）
到达路径 ① MediaSession 回调（主）② MediaButtonReceiver 广播（备）③ 通知栏动作（备）
前提 播放器必须活在常驻服务里，不能绑在界面上
响应 按键后 500ms 内状态变化

规则

  • 界面关闭、切到导航、锁屏，按键仍然生效。
  • 部分车机固件只在开机时扫描一次媒体源，所以需要开机自启，让媒体会话尽早存在。
  • 若车机厂商固件根本不派发按键事件，需如实标注为「设备限制」，不可虚报支持。

验收

  • 按 Home 键退出应用后，方向盘按键仍能切台
  • 车机左下媒体区显示本应用，且台名/状态随播放变化

F6 · 车机媒体中心集成

必须提供

  • 前台服务常驻 + MediaSession，提供：台名、副标题（如「正在直播」）、台标图、播放状态。
  • 通知栏：台标 + 台名 + 播放暂停 / 上一台 / 下一台。
  • 台标同时写入媒体元数据，供锁屏、蓝牙车机、通知栏大图读取。

验收

  • 车机左下媒体播放区出现本应用条目
  • 台名随切台更新（不是固定文案）
  • 通知栏三个按钮可用

F7 · 播放区信息展示与列表跟随

播放区必须显示的 5 个元素

元素 要求
圆形台标 官方台标图，方形图裁成圆形铺满；长条形台标完整显示、不裁切不拉伸、留白；无图时回落台名字标，不空白
台名 大字号，可两行
直播状态 「● 正在直播」，暂停时显示灰色「‖ 已暂停」
节目时段 显示当前时段名称与起止时间（如「00:00–24:00」）
时间轴 进度条 + 时间码（当前时间 / 总时长）

列表跟随规则（重要）

  1. 界面行号 ≠ 播放队列下标（有隐藏台、有收藏视图），必须按电台唯一 ID 换算。
  2. 切台后，若目标行在可见区域内 → 不动（用户可能正在翻别的台看）。
  3. 目标行不可见 → 滚动到该行，上方留 1~3 行余量，不贴屏幕边缘。
  4. 滚动必须在列表数据刷新之后执行，否则会被随后的一次重新布局冲掉（常见 bug）。

验收

  • 连按下一台 12 次，高亮行始终可见（会翻页）
  • 往回切时列表跟回来
  • 隐藏 2 个台后，高亮与实际播放台不错位

F8 · 收藏列表

  • 每行一个「☆/★」按钮，点击加入/移出收藏，星标状态即时切换。
  • 顶部 Tab 切换「全部电台 / 收藏」，两个列表独立。
  • 收藏与隐藏是两套独立数据，互不影响。
  • 收藏为空时显示引导文案（如「点列表右侧 ☆ 添加」）。
  • 收藏列表持久化，重启后保留。

验收

  • 收藏后切到收藏 Tab 可见该台
  • 重启应用收藏仍在
  • 取消收藏后从收藏 Tab 消失，但仍在全部电台中

F9 · 隐藏电台

  • 每行一个「⊘」按钮，点击隐藏（可恢复）。
  • 隐藏后立即从全部电台与收藏列表中移除。
  • 隐藏台同步移出播放队列，方向盘不会切到。
  • 隐藏状态持久化；提供「恢复」入口。
  • 全部台都被隐藏时，完整保留列表而不是显示空白，避免用户无法操作。

验收

  • 隐藏当前正在播的台 → 自动切到下一台
  • 隐藏后方向盘连按，不会切到被隐藏的台
  • 可以从恢复入口找回

F10 · 开机续播（核心难点）

必须记住的字段

字段 作用
contentId 电台唯一 ID，主要依据（列表增删也不错位）
index 下标，兜底（万一该台被下架）
省份编码 / 名称 上次在哪个「文件夹」
是否在播 退出时是播放还是暂停
省份是否用户手选 决定下次启动要不要强制恢复该省份
当前视图 全部 / 收藏
隐藏清单、收藏清单 独立存储

规则

  1. 省份与电台必须成对恢复。只恢复电台不恢复省份 → 出现「记的是 A 省的台，列表却是 B 省」，等于没恢复。
  2. 区分「用户手选」与「定位推出」： - 用户手动选过省份 → 下次启动强制恢复该省份，不跟随定位。 - 从未手选（全靠定位）→ 下次启动允许跟随定位，自动切到当地。
  3. 恢复只消费一次，且要防止重复请求导致状态被冲掉。 - 典型 bug：切到第 5 台，退出重进却回到第 1 台 —— 多因恢复逻辑被调用两次或与初始化请求竞争。
  4. 不存播放 URL。地址带签名，存下来必然失效，必须播放时重新申请。

验收

  • 切到第 5 台 → 退出 → 重进 → 仍是第 5 台且列表在第 5 行
  • 手动切到重庆 → 退出 → 重进 → 仍是重庆
  • 从未手选省份 → 换城市后重进 → 跟随新城市

F11 · 地区切换

  • 顶栏一个省份下拉，列出 34 个省级行政区 + 国家台。
  • 切换后立即拉取该省列表并重建队列。
  • 切换省份记为「用户手选」（影响 F10）。
  • 顶栏省份文字需限制最大宽度，过长截断，不得挤掉其它控件。

F12 · 手势换台

  • 区域：仅播放区（上半区），列表区不响应（否则与滚动冲突）。
  • 判定：位移超过阈值才触发。上滑/左滑 = 下一台，下滑/右滑 = 上一台。
  • 阈值：车机 90dp，手机 48dp（可调）。
  • 事件模式：监听但不拦截，正常分发不受影响。

验收

  • 左滑换下一台，右滑换上一台
  • 列表区上下滑动只会滚动列表，不会换台
  • 轻微误触不换台

F13 · 手机适配（P2，可选）

同一 APK 兼容手机，判据建议：

两栏布局 = 宽 ≥ 高 且 高 ≥ 520dp
紧凑尺寸 = 短边 < 600dp 且（高度 < 520dp 或 宽 < 高 × 1.2）
  • 车机 960×540dp → 两栏 + 原尺寸（保持 28sp 车规大字号）
  • 手机竖屏 → 单列 + 紧凑
  • 手机横屏（如 780×360dp）→ 单列（高度不够两栏）

注意：判据必须同时看高度和宽高比。只判短边会把车机（短边 540dp）误判成手机，把车规字号缩小。

F14 · 应用内诊断日志

车机无 USB 调试，日志必须能在界面上看到：

  • 保留最近 500 条环形缓冲，带时间戳与分类标签（网络 / 播放 / 界面 / 列表）。
  • 界面提供入口查看、复制、清空。
  • 关键节点必须打日志：定位结果、接口请求与失败原因、地址切换、降级动作、恢复快照、切台与滚动目标行。

5. 数据接口要求

数据 用途 要求
省级行政区列表 地区下拉 一次请求，可缓存
某省电台列表 列表 + 播放地址 每台含 4 个播放地址
电台台标图 界面显示 通常 400×400，本地缓存，断网可用
IP 归属地 自动定位 只需省级 + 城市名，4 秒超时
节目时段 时间轴 无则显示「00:00-24:00」占位

接口约束

📎 完整字段说明、签名算法、错误码、地址有效期实测见单独文档 接口字段说明.md / .html。

  • 接口为公开接口，不得绕过鉴权、不得逆向私有接口。
  • 接口可能变更；需具备后台可切换基地址的能力，避免一次变更导致整体不可用。
  • 请求需带固定请求头（equipmentId、platformCode），具体值以官方网页端为准。

合规边界（必须遵守）

  1. 只读取公开接口，不下载、不转存、不分发音频内容。
  2. 不复用原厂 App 的任何代码、图标、字体、私有接口。
  3. 不做付费内容/会员功能。
  4. 不采集任何个人信息，IP 仅用于省份判断且不上报。

6. 异常与降级汇总

场景 期望行为
IP 定位失败/超时 回落默认省份，不弹错误、不阻塞
省份列表接口挂了 用内置省份清单（34 个 + 国家台）
电台列表为空 显示空态文案，保留操作入口
播放地址 403/过期 重新申请后重试；仍失败则提示
断网 可用缓存地址继续播放已有音频；列表显示离线提示
台标图下载失败 回落为台名文字标
服务被系统回收 通过 START_STICKY 自动重建，恢复播放状态
所有电台被隐藏 完整保留列表，避免白屏
收藏列表为空 显示引导文案
来电 / 导航播报 自动压低或暂停，结束后恢复
网络切换（4G ↔ WiFi） 自动续播，不出现长时间静音无响应

7. 验收清单

功能（必须全部通过）

  • 全新安装 → 自动显示本省电台
  • 三个控制按钮单击即生效
  • 方向盘上一曲/下一曲/暂停均生效（需实车）
  • 车机左下媒体区显示本应用与台名
  • 连按下一台 12 次，列表跟随翻页且高亮正确
  • 收藏 → 切换 Tab 可见 → 重启后仍在
  • 隐藏 → 从列表与队列同时消失 → 可恢复
  • 切到第 N 台 → 退出 → 重进 → 回到第 N 台
  • 手动切换省份 → 重进后仍是该省
  • 断网 → 不崩溃、有明确提示

非功能

  • 冷启动到可操作 ≤ 2 秒
  • 安装包 ≤ 1 MB（推荐目标，非硬性）
  • 常驻内存 ≤ 100 MB
  • 连续播放 4 小时无内存增长、无 ANR
  • 无任何广告/统计 SDK（可通过反编译或依赖清单核验）

8. 交付物要求

  1. 可安装 APK（签名，Android 9 可用）
  2. 源码仓库（含构建说明，可一键出包）
  3. 单元测试（至少覆盖：排序规则、队列下标 ↔ 界面行号换算、恢复逻辑、地址降级）
  4. 功能说明文档（面向使用者，非开发者）
  5. 已知限制清单（如实标注未验证项，例如方向盘按键是否依赖特定固件）

9. 开发优先级建议

阶段 内容 说明
第 1 阶段 F1 + F2 + F3 + F4 能定位、能出列表、能播能切，最小可用
第 2 阶段 F5 + F6 + F10 方向盘、媒体中心、续播，这三项决定"能不能当车机收音机用"
第 3 阶段 F7 + F8 + F9 + F11 体验补齐：信息展示、收藏、隐藏、地区切换
第 4 阶段 F12 + F13 + F14 手势、手机适配、诊断日志

最容易翻车的三处（提前提醒开发方）

  1. F3 单击不生效 —— 触屏焦点坑，几乎每个车机项目都会踩。
  2. F7 列表不跟随 —— 行号算错 + 滚动被重新布局冲掉，两个原因叠加。
  3. F10 回到第一个台 —— 恢复逻辑执行两次或与初始化请求竞争。
